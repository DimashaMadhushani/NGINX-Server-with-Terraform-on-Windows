# Provisioning NGINX with Terraform and Docker on Windows
This project is a hands-on guide to provisioning an NGINX web server container using Terraform and Docker on a Windows machine. It demonstrates the basics of Infrastructure as Code (IaC) with a practical example. You’ll learn how to:

Create a Terraform configuration file

Pull and run an NGINX Docker container

Serve it on http://localhost:8000

Destroy the container setup with a single command
